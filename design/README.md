# North Nectar website (browser-ready)

Double-click `index.html` to open the site in Chrome, Edge or Firefox. No server or install needed.

## Pages
- `index.html`: Home (light hero)
- `home-dark.html`: Home (dark hero)
- `shop.html`, `product.html`, `about.html`, `contact.html`
- `cart-drawer.html`, `cart.html`, `checkout.html`, `confirmation.html`

## States (add to the address)
- `contact.html?view=errors` or `contact.html?view=success`
- `checkout.html?view=errors`
- `cart.html?view=empty`
- `index.html?variant=dark`

## Notes
- Needs internet only for the Google Fonts (Oswald and Figtree).
- `assets/` holds all images, videos and the two scripts (`preact.min.js` runtime and `site.js` with every page).
- Pages are responsive: resize the window or open on a phone to see the mobile layout.
